Registration Link Management

Generate temporary authorization links for new broadcasters.

User Registration

Creates a standard registration link with Twitch chat access. The link remains valid for 10 minutes and may be used once.

SYNARA User Registration

Grants the additional Twitch permission required for SYNARA to send chat messages. Use this only when the user is intentionally registering for SYNARA.

Active Links

Links are automatically removed when they expire or are used. A maximum of 3 active links may exist at once.
